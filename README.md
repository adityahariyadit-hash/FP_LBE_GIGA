About
TotallyNormalGame is a small Flappy Bird-inspired game made with Python and Pygame.

The objective is simple:

Fly through the pipes.

Get as many points as possible.

Keep going.

Don't worry about anything unusual.

Just keep playing.

It's a perfectly normal game.

Features
🐦 Simple Flappy Bird-style gameplay

🎮 Keyboard controls

🚧 Randomly generated pipes

📊 Score system

🌑 Dynamic visual changes

🎵 Multiple sound effects and soundtracks

👾 Special chase sequence

⏱️ 14-second survival challenge

💀 Multiple game-over scenarios

😐 Completely normal gameplay

Control:
only "space"
